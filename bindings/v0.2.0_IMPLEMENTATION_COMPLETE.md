## 📝 Implementation Patterns

### Common Features Across All SDKs

1. **OperationSchema**
   - name (required)
   - inputSchema (required, JSON Schema)
   - title (optional)
   - description (optional)
   - outputSchema (optional, JSON Schema)
   - annotations (optional, key-value metadata)

2. **ServerInfo**
   - server (required)
   - version (required)
   - protocol (required)
   - features (optional, array)
   - operationsCount (optional, integer)
   - mcpCompatible (optional, boolean)
   - metadata (optional, key-value)

3. **DiscoverableService Interface**
   - listOperations() - Returns all operations
   - getSchema(name) - Returns specific operation schema
   - getServerInfo() - Returns server metadata

4. **Helper Utilities**
   - generateOperationsResponse() - For _list_operations endpoint
   - generateSchemaResponse() - For _get_schema endpoint
   - generateServerInfoResponse() - For _server_info endpoint

5. **Reference Implementation**
   - SimpleDiscoverableService - Basic implementation for testing/examples
