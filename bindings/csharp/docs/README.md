## 🚀 Quick Start

```bash
# Build the SDK
dotnet build --configuration Release

# Run tests
dotnet test --configuration Release

# Run examples
dotnet run --project ../Umicp.Examples

# Generate coverage report
dotnet test /p:CollectCoverage=true
```
