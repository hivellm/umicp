## 🚀 Publishing to Maven Central

### Prerequisites

1. **Sonatype Account**: https://issues.sonatype.org/secure/Signup!default.jspa
2. **GPG Key**: For signing artifacts
3. **Gradle**: Configured with credentials

### Setup

#### 1. Generate GPG Key

```bash
# Generate key
gpg --gen-key

# List keys
gpg --list-keys

# Export public key
gpg --keyserver keyserver.ubuntu.com --send-keys YOUR_KEY_ID

# Export private key (for signing)
gpg --export-secret-keys YOUR_KEY_ID > ~/.gnupg/secring.gpg
```

#### 2. Configure Gradle

Add to `~/.gradle/gradle.properties`:

```properties
# Signing
signing.keyId=YOUR_KEY_ID_LAST_8_CHARS
signing.password=YOUR_GPG_PASSWORD
signing.secretKeyRingFile=/path/to/.gnupg/secring.gpg

# Or use in-memory key (recommended for CI)
signingKeyId=YOUR_KEY_ID
signingKey=YOUR_ASCII_ARMORED_GPG_KEY
signingPassword=YOUR_GPG_PASSWORD

# Sonatype OSSRH
ossrhUsername=YOUR_SONATYPE_USERNAME
ossrhPassword=YOUR_SONATYPE_PASSWORD
```

#### 3. Or Use Environment Variables

```bash
# Linux/macOS
export ORG_GRADLE_PROJECT_signingKeyId=YOUR_KEY_ID
export ORG_GRADLE_PROJECT_signingKey="$(cat ~/.gnupg/private.key)"
export ORG_GRADLE_PROJECT_signingPassword=YOUR_PASSWORD
export ORG_GRADLE_PROJECT_ossrhUsername=YOUR_USERNAME
export ORG_GRADLE_PROJECT_ossrhPassword=YOUR_PASSWORD

# PowerShell
$env:ORG_GRADLE_PROJECT_signingKeyId="YOUR_KEY_ID"
$env:ORG_GRADLE_PROJECT_signingKey=Get-Content ~/.gnupg/private.key -Raw
$env:ORG_GRADLE_PROJECT_signingPassword="YOUR_PASSWORD"
$env:ORG_GRADLE_PROJECT_ossrhUsername="YOUR_USERNAME"
$env:ORG_GRADLE_PROJECT_ossrhPassword="YOUR_PASSWORD"
```

## 📋 Publishing Steps

### Method 1: Using Scripts (Recommended)

```bash
# Build and test
./build.sh          # Linux/macOS
.\build.ps1         # Windows

# Publish
./publish.sh        # Linux/macOS
.\publish.ps1       # Windows
```

### Method 2: Manual Gradle

```bash
# 1. Clean and test
./gradlew clean test

# 2. Build all artifacts
./gradlew build

# 3. Publish to local Maven (test)
./gradlew publishToMavenLocal

# 4. Publish to Maven Central
./gradlew publish

# 5. Close and release on Sonatype (manual step)
# Visit: https://s01.oss.sonatype.org/
```

## 🆘 Troubleshooting

### Signing Fails

- Check GPG key is valid: `gpg --list-keys`
- Verify password is correct
- Ensure key is uploaded to keyserver

### Sonatype Authentication Fails

- Verify credentials at https://s01.oss.sonatype.org/
- Check username/password in gradle.properties
- Ensure JIRA account is approved for `com.hivellm` group

### Build Fails

```bash
# Clear Gradle cache
./gradlew clean --no-daemon

# Or delete .gradle directory
rm -rf ~/.gradle/caches
```
