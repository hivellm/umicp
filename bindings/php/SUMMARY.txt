================================================================================
                           PROJECT OVERVIEW
================================================================================

OBJECTIVE:
  Create high-performance PHP bindings for UMICP (Universal Matrix Intelligent
  Communication Protocol) enabling PHP applications to participate in AI model
  inter-communication with sub-millisecond latency.

KEY FEATURES:
  ✓ FFI Integration with C++ Core
  ✓ High-Performance Matrix Operations
  ✓ WebSocket Client & Server
  ✓ Multiplexed Peer Architecture (P2P)
  ✓ Auto-Handshake Protocol
  ✓ ReactPHP/Swoole Support
  ✓ Framework Agnostic (Symfony, Laravel, etc.)

REQUIREMENTS:
  • PHP 8.1 or higher
  • FFI extension enabled
  • C++ compiler (GCC 7+, Clang 5+, MSVC 2019+)
  • CMake 3.15+

                         API DESIGN PREVIEW
================================================================================

ENVELOPE API:
  $envelope = new Envelope(
      from: 'sender-001',
      to: 'receiver-001',
      operation: OperationType::DATA,
      capabilities: ['message' => 'Hello!']
  );
  $json = $envelope->serialize();
  $received = Envelope::deserialize($json);

MATRIX API:
  $matrix = new Matrix();
  $dotProduct = $matrix->dotProduct($vec1, $vec2);
  $similarity = $matrix->cosineSimilarity($vec1, $vec2);
  $sum = $matrix->vectorAdd($vec1, $vec2);

MULTIPLEXED PEER API:
  $peer = new MultiplexedPeer(
      peerId: 'php-agent',
      loop: $loop,
      serverConfig: ['port' => 20081]
  );
  $peer->on('data', function($envelope, $peer) { /* ... */ });
  $peer->connectToPeer('ws://localhost:20082/umicp');
