## 🚀 Quick Start Preview

### Installation (Planned)
```bash
composer require hivellm/umicp
```

### Basic Usage
```php
use UMICP\Core\Envelope;
use UMICP\Core\OperationType;

$envelope = new Envelope(
    from: 'client-001',
    to: 'server-001',
    operation: OperationType::DATA,
    capabilities: ['message' => 'Hello UMICP!']
);

$json = $envelope->serialize();
echo $json;
```

### Multiplexed Peer
```php
use React\EventLoop\Loop;
use UMICP\Transport\MultiplexedPeer;

$loop = Loop::get();
$peer = new MultiplexedPeer('php-agent', $loop);

$peer->on('data', function($envelope, $peer) {
    echo "Received: {$envelope->getFrom()}\n";
});

$peer->connectToPeer('ws://localhost:20082/umicp');
Loop::run();
```
